8 interactieve lessen

Werk de lessen in volgorde af. Je voortgang wordt op deze computer onthouden.

0 van 8 lessen voltooid

1. Repository begrijpen

Een repository (repo) is een map voor een project. GitHub bewaart er bestanden én de geschiedenis van wijzigingen.

Opdracht: Zoek in jullie teamrepository de README.md en bekijk waarvoor die dient.
2. Een repository clonen

Met git clone maak je een lokale kopie van een repository op je computer.

Opdracht: Clone de teamrepository en controleer of je de bestanden lokaal ziet.
3. Status controleren

Met git status zie je welke bestanden gewijzigd, nieuw of klaar voor een commit zijn.

Opdracht: Wijzig één tekstbestand en voer daarna git status uit.
4. Bestanden toevoegen aan staging

Met git add kies je welke wijzigingen je in de volgende commit wilt opnemen.

Opdracht: Voeg jouw gewijzigde bestand toe met git add.
5. Een commit maken

Een commit is een opgeslagen momentopname van je werk. Gebruik een korte, duidelijke commitboodschap.

Opdracht: Maak een commit met een boodschap zoals: Voeg uitleg over branches toe.
6. Werken met branches

Een branch laat je aan een onderdeel werken zonder de hoofdbranch meteen te wijzigen. Dit maakt samenwerken veiliger.

Opdracht: Maak een eigen branch voor jouw onderdeel en werk alleen daarop.
7. Pushen naar GitHub

Met git push stuur je lokale commits naar de online repository op GitHub.

Opdracht: Push jouw branch naar GitHub en controleer of die online zichtbaar is.
8. Pull request en merge

Met een pull request laat je teamleden jouw wijzigingen nakijken. Na goedkeuring kunnen ze in de hoofdbranch worden samengevoegd.

Opdracht: Open een pull request en beschrijf kort wat je hebt aangepast.
Tip: commit vaak en schrijf duidelijke commitboodschappen.
